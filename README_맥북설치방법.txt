🧀 TastyPop Studio — 맥북 원클릭 쇼츠 자동화 패키지
=========================================================
유튜브 @TastyPop_Story · 인스타 @tastypop_story 운영용
버전 1.0 / macOS (Apple Silicon · Intel 모두 가능)


■ 이 프로그램이 해 주는 일
---------------------------------------------------------
· 무대사 3D 음식 ASMR 쇼츠 (13.5~19초, 9~10컷 밀당 리듬)
· 4인방 캐릭터 숏폼 드라마 (16.5~21.5초, 한국어 대사 + 영어 자막)
· 0.000초 임팩트 → 0.900초 훅 자막 칼소멸 → 중간 대형 컷 → 눈치 윙크 CTA → 0.25초 무한루프
· ASMR 사운드 20종 자체 내장 (저작권 0원)
· 유튜브·인스타 업로드 카피 자동 생성 (제목·설명·해시태그·고정댓글·3지선다 투표)
· 유튜브 예약 자동 업로드 / 인스타 릴스 패키지(ZIP) / 로컬 MP4 저장
· 채널 전략 분석 → 승인하면 바로 제작, 댓글 답글 도우미, 일일 자동 예약
· 모든 버튼·안내가 한글


■ 설치 (처음 한 번, 5분)
---------------------------------------------------------
1) 이 폴더를 원하는 곳에 둡니다. (예: 홈 폴더)
   * 다운로드 폴더에 그대로 두셔도 됩니다.

2) "start.command" 를 더블클릭합니다.

   ⚠️ 처음에 "확인할 수 없는 개발자가 만든 파일입니다" 창이 뜨면
      → 파일을 오른쪽 클릭 → [열기] → [열기] 를 누르면 됩니다.
      (한 번만 허용하면 다음부터는 그냥 더블클릭으로 실행됩니다.)

3) 터미널 창이 열리고 자동으로:
   - 파이썬 가상환경(.venv) 생성
   - 필요한 패키지 설치 (3~6분, 처음 한 번만)
   - 대시보드 실행 → 브라우저가 자동으로 열립니다
     주소: http://localhost:8766

4) 이 창을 닫으면 프로그램이 종료됩니다. (창을 최소화해 두고 쓰세요)

※ 터미널에서 직접 설치하고 싶다면:
   cd ~/Downloads/TastyPop_Studio
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python -m uvicorn app.main:app --port 8766


■ ffmpeg (영상 엔진)
---------------------------------------------------------
· 없어도 자동 대체 바이너리(imageio-ffmpeg)로 동작합니다.
· 더 빠르고 안정적으로 쓰시려면 터미널에서:
      brew install ffmpeg
  (brew 가 없으면 먼저: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)")
· 맥북 하드웨어 가속(h264_videotoolbox)은 자동 감지되며,
  지원되지 않으면 libx264 로 자동 전환됩니다. (대시보드 상단에 표시)


■ 3분 사용법
---------------------------------------------------------
[1] [제작] 탭
    - 주제를 직접 쓰거나, 🔮 주제 추천기에서 카테고리(분식·치즈야식·겨울간식·
      편의점·디저트·4인방)를 눌러 추천을 고릅니다.
    - 길이 프리셋(13.5 / 16.5 / 18 / 19초)과 슬라이더로 조절합니다.
    - 이탈률 제로 공식 8가지(훅·임팩트·3컷·중간장치·윙크·CTA·루프·스우시)는
      기본으로 전부 ON 입니다. 원하시면 끄면 됩니다.
    - [프로젝트 만들기] → 프로젝트 폴더와 이미지_요청서.txt 가 생성됩니다.

[2] 이미지 준비 (두 가지 방법 중 선택)
    A. 0원 협업 모드 (추천)
       - 프로젝트 폴더의 kf/ 안에 c01.png, c02.png … 를 넣습니다.
       - 이미지 요청서.txt 를 그대로 케빈에게 보내면 컷별 프롬프트를 받습니다.
       - 영상 클립이 있으면 clips/ 에 c01.mp4 … 로 넣어도 됩니다.
    B. 완전자동 API 모드
       - [설정]에서 Gemini / Kling 키를 넣고 [이미지 자동 생성] → [영상 조립].

[3] [영상 조립] 클릭 → 진행률과 로그가 실시간으로 표시됩니다.
    1080x1920 · 30fps · -12.5 LUFS · 무음 0 · 워터마크 0 으로 자동 검증됩니다.

[4] [업로드 카피] 탭
    - 유튜브 제목(70자 이내, | K-Food 3D Ep.N) / 설명 / 해시태그 / 고정댓글
    - 인스타 [Ep.N] 캡션 + 3지선다 투표 고정댓글 + 체크리스트
    - 각 항목의 [복사] 버튼으로 바로 붙여넣기

[5] 업로드 방법 3가지 (프로젝트 화면 📤 업로드 방법)
    ① YouTube 예약 자동 업로드
       - [유튜브 예약] 탭에서 날짜·시간 선택 → [업로드 시작]
       - 기본 골든타임 19:00~20:30
       - 업로드와 동시에 **첫 고정댓글(한·영 합본)이 자동 등록**됩니다.
         · 즉시 공개: 업로드 직후 바로 댓글 게시
         · 예약 공개: 공개 10초 전부터 10초 간격으로 공개 여부를 확인해,
           공개되는 즉시 1등 댓글로 자동 등록 (유튜브 API 는 핀 고정 기능이 없어
           상단 고정 핀만 앱/웹에서 1클릭)
    ② 인스타 릴스 패키지 + 체크리스트
       - MP4 + 캡션 + 고정댓글 + 체크리스트가 ZIP 으로 저장됩니다.
       - 인스타는 앱에서 직접 업로드합니다(웹 자동화 차단).
    ③ 로컬 MP4 + 카피만 저장

[6] [채널 전략] 탭 → [다시 분석]
    - 채널 영상의 조회수·좋아요·댓글·길이·업로드 시간대를 분석해
      · 가장 반응 좋은 음식 카테고리
      · 가장 반응 좋은 영상 길이(초)
      · 골든타임 업로드 시각
      을 계산해 카드로 보여 줍니다.
    - [✅ 이 전략으로 바로 제작하기] 를 누르면 추천 주제·길이·시간이 그대로 세팅되어
      바로 제작이 시작됩니다.
    - [댓글 답글] 탭에서는 국내(한국어)·해외(영어) 댓글에 맞는 재치 답글 초안을
      두 가지로 보여 주고, 원클릭으로 등록합니다.


■ 수정 지시 (가장 강력한 기능)
---------------------------------------------------------
프로젝트를 연 뒤 [✏️ 수정 지시] 칸에 한 줄로 적고 [지시 반영]:
   "3컷 더 빠르게, 치즈 늘어나는 소리 크게"
   "전체 19초로 늘리고 마지막 컷 길게"
   "훅을 Can you handle Lv.999? 로 바꿔"
   "루프 끄고 플래시 켜"
· AI 키가 있으면 장면 묘사·대사까지 다시 씁니다.
· 키가 없어도 컷 길이·효과음 볼륨·훅 문구·옵션 토글은 항상 조정됩니다.
· 컷별 장면/대사/효과음은 에디터에서 직접 고치고 [저장] 하면 됩니다.


■ API 키 (선택)
---------------------------------------------------------
[설정] 탭에서 입력하면 config/settings.json 에만 저장됩니다(절대 GitHub 에 안 올라감).
· Gemini : 대본 + 이미지 생성
· OpenAI / Claude : 대본 대안
· Kling  : 이미지를 영상으로 (Access Key + Secret Key 또는 API Key)

■ 유튜브 자동 업로드 준비 (처음 한 번)
---------------------------------------------------------
1) https://console.cloud.google.com → 새 프로젝트
2) [API 및 서비스] → [라이브러리] → "YouTube Data API v3" 사용 설정
3) [사용자 인증 정보] → [OAuth 클라이언트 ID] → 애플리케이션 유형: 데스크톱 앱
4) JSON 다운로드 → 파일 이름을 client_secret.json 으로 바꿔 이 폴더의 config/ 안에 저장
5) 대시보드 [유튜브 예약] 탭 → [🔑 유튜브 로그인] → 브라우저에서 채널 선택
※ 구글 앱 심사 전에는 API 업로드가 '비공개'로만 올라갈 수 있습니다.
   → 스튜디오에서 예약/공개로 한 번만 바꾸거나, 앱 인증을 받으면 완전 무인 예약이 됩니다.


■ 이미지 0원 자동 연결 (가장 빠른 길)
---------------------------------------------------------
방법 1. 구글 AI Studio 무료 키 (완전자동)
   - [설정] → Gemini API 키 칸에 무료 키 입력
     발급: https://aistudio.google.com/apikey (무료 티어)
   - [이미지 자동 생성] 을 누르면 컷별 키프레임이 자동으로 만들어집니다.
   - 무료 한도를 넘으면 다음 날 자동 복구되며, 그동안은 방법 2로 이어가면 됩니다.

방법 2. 케빈 0원 협업 (가장 확실)
   - 프로젝트 화면의 [📋 케빈에게 보낼 이미지 요청서 복사] 를 누르고 케빈에게 붙여넣기
   - 케빈이 GitHub 저장소의 assets_inbox/Ep8_불닭떡볶이/ 에 kf1.png ~ kf10.png 를 올림
   - 맥북에서 [🔄 최신 버전 업데이트] → [프로젝트] 탭의
     [📥 GitHub로 받은 이미지] 에 새 묶음이 나타남
   - [📥 프로젝트에 가져오기] 한 번 → kf/ 폴더로 자동 복사
   - 모든 컷이 차면 초록불이 켜지고 **영상 조립이 자동으로 시작**됩니다.

※ 직접 넣어도 됩니다: projects/{프로젝트}/kf/ 에 kf1.png ~ kf10.png 또는 c01.png ~ c10.png
   → 대시보드가 5초마다 자동 감지해 초록불을 켜고 다음 단계로 넘어갑니다.


■ 수익창출 보호 · 증빙 자동 백업
---------------------------------------------------------
영상이 완성되면 매 편마다 projects/{ep_id}/evidence/ 가 자동 생성됩니다:
   · keyframes/  : 컷별 키프레임 원본
   · clips/      : 영상화 원본 클립(Kling 결과 등)
   · timeline.json : 컷 길이·훅·CTA·수정 이력 전체
   · sound_sources.json : 사용한 사운드의 출처·라이선스(전부 CC0)
   · ai_disclosure.txt : AI 고지 문구
   · manifest.json : 파일별 SHA-256 해시(원본 무결성 증명)
프로젝트 화면에서 [지금 백업] 으로 언제든 다시 만들 수 있습니다.

■ 자주 묻는 문제
---------------------------------------------------------
Q. "start.command" 더블클릭이 안 돼요
A. 오른쪽 클릭 → [열기]. 그래도 안 되면 터미널에서:
     chmod +x start.command && ./start.command

Q. 브라우저가 안 열려요
A. 직접 http://localhost:8766 을 여세요.

Q. "포트가 이미 사용 중" 이라고 나와요
A. 이전 창이 켜져 있을 가능성이 큽니다. 그 창을 닫고 다시 실행하세요.
   (포트 변경: config/settings.json 의 "server": {"port": 8767})

Q. 영상이 너무 느리게 만들어져요
A. 컷 준비 단계가 가장 오래 걸립니다. 처음 한 번은 인코더 감지 때문에 더 걸립니다.
   훨씬 빠르게 하려면: brew install ffmpeg

Q. 유튜브 업로드가 '비공개'로만 돼요
A. 구글 앱 심사 전 상태라 그렇습니다. 스튜디오에서 예약/공개로 바꾸거나
   Google Cloud Console 에서 OAuth 앱 인증을 완료하세요.

Q. image_request 의 c01.png 는 어디에 넣나요?
A. projects/프로젝트이름/kf/ 폴더입니다. 대시보드 [📂 폴더 열기] 로 바로 열 수 있습니다.
