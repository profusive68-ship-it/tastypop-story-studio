🧀 TastyPop Studio — 맥북 원클릭 쇼츠 자동화 패키지
=========================================================
유튜브 @TastyPop_Story · 인스타 @tastypop_story 운영용
버전 1.2.0 / macOS (Apple Silicon · Intel 모두 가능)


■ 이 프로그램이 해 주는 일
---------------------------------------------------------
· 무대사 3D 음식 ASMR 쇼츠 (13.5~19초, 9~10컷 밀당 리듬)
· 4인방 캐릭터 숏폼 드라마 (16.5~21.5초, 한국어 대사 + 영어 자막)
· 0.000초 임팩트 → 0.900초 훅 자막 칼소멸 → 중간 대형 컷 → 눈치 윙크 CTA → 0.25초 무한루프
· ASMR 사운드 20종 자체 내장 (저작권 0원)
· 유튜브·인스타 업로드 카피 자동 생성 (제목·설명·해시태그·고정댓글·3지선다 투표)
· 유튜브 예약 자동 업로드 / 인스타 릴스 패키지(ZIP) / 로컬 MP4 저장
· 채널 전략 분석 → 승인하면 바로 제작, 댓글 답글 도우미, 일일 자동 예약
· [📤 케빈에게 이미지 요청하기] 한 번 → 깃허브 이슈로 요청, 케빈이 올린 이미지는 20초마다 자동 수신
· 컷별 이미지 미리보기 갤러리 + [✏️ 이미지 수정 요청] + [🎬 영상(클립) 제작 요청]
· 클립(.mp4)이 나중에 도착하면 이미 만든 영상도 자동으로 다시 조립(덮어쓰기)
· 모든 버튼·안내가 한글


■ 설치 (처음 한 번, 5분)
---------------------------------------------------------
1) 이 폴더를 원하는 곳에 둡니다. (예: 홈 폴더)
   * 다운로드 폴더에 그대로 두셔도 됩니다.

2) "start.command" 를 더블클릭합니다.

   ⚠️ 처음에 "확인할 수 없는 개발자가 만든 파일입니다" 창이 뜨면
      → 파일을 오른쪽 클릭 → [열기] → [열기] 를 누르면 됩니다.
      (한 번만 허용하면 다음부터는 그냥 더블클릭으로 실행됩니다.)

3) 터미널 창이 열리고 자동으로:
   - 파이썬 가상환경(.venv) 생성
   - 필요한 패키지 설치 (3~6분, 처음 한 번만)
   - 대시보드 실행 → 브라우저가 자동으로 열립니다
     주소: http://localhost:8766

4) 이 창을 닫으면 프로그램이 종료됩니다. (창을 최소화해 두고 쓰세요)

※ 터미널에서 직접 설치하고 싶다면:
   cd ~/Downloads/TastyPop_Studio
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python -m uvicorn app.main:app --port 8766


■ ffmpeg (영상 엔진)
---------------------------------------------------------
· 없어도 자동 대체 바이너리(imageio-ffmpeg)로 동작합니다.
· 더 빠르고 안정적으로 쓰시려면 터미널에서:
      brew install ffmpeg
  (brew 가 없으면 먼저: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)")
· 맥북 하드웨어 가속(h264_videotoolbox)은 자동 감지되며,
  지원되지 않으면 libx264 로 자동 전환됩니다. (대시보드 상단에 표시)


■ 3분 사용법
---------------------------------------------------------
[1] [제작] 탭
    - 주제를 직접 쓰거나, 🔮 주제 추천기에서 카테고리(분식·치즈야식·겨울간식·
      편의점·디저트·4인방)를 눌러 추천을 고릅니다.
    - 길이 프리셋(13.5 / 16.5 / 18 / 19초)과 슬라이더로 조절합니다.
    - 이탈률 제로 공식 8가지(훅·임팩트·3컷·중간장치·윙크·CTA·루프·스우시)는
      기본으로 전부 ON 입니다. 원하시면 끄면 됩니다.
    - [프로젝트 만들기] → 프로젝트 폴더와 이미지_요청서.txt 가 생성됩니다.

[2] 이미지 준비 (두 가지 방법 중 선택)
    A. 0원 협업 모드 (추천)
       - 프로젝트 화면의 [📤 케빈에게 이미지 요청하기] 를 누릅니다.
         → 케빈에게 깃허브 이슈가 생기고, 요청서는 클립보드에도 복사됩니다.
       - 케빈이 `assets_inbox/{프로젝트ID}/` 에 kf1.png ~ 를 올리면
         맥북이 20초마다 자동으로 내려받아 `kf/` 에 넣고, 전 컷이 차면 영상 조립까지 자동 시작합니다.
         (로그에 “🎉 케빈이 올린 이미지 자동 수신 완료!” 가 뜨면 정상입니다)
    B. 완전자동 API 모드
       - [설정]에서 Gemini / Kling 키를 넣고 [이미지 자동 생성] → [영상 조립].

[3] [영상 조립] 클릭 → 진행률과 로그가 실시간으로 표시됩니다.
    1080x1920 · 30fps · -12.5 LUFS · 무음 0 · 워터마크 0 으로 자동 검증됩니다.

[4] [업로드 카피] 탭
    - 유튜브 제목(70자 이내, | K-Food 3D Ep.N) / 설명 / 해시태그 / 고정댓글
    - 인스타 [Ep.N] 캡션 + 3지선다 투표 고정댓글 + 체크리스트
    - 각 항목의 [복사] 버튼으로 바로 붙여넣기

[5] 업로드 방법 3가지 (프로젝트 화면 📤 업로드 방법)
    ① YouTube 예약 자동 업로드
       - [유튜브 예약] 탭에서 날짜·시간 선택 → [업로드 시작]
       - 기본 골든타임 19:00~20:30
       - 업로드와 동시에 **첫 고정댓글(한·영 합본)이 자동 등록**됩니다.
         · 즉시 공개: 업로드 직후 바로 댓글 게시
         · 예약 공개: 공개 10초 전부터 10초 간격으로 공개 여부를 확인해,
           공개되는 즉시 1등 댓글로 자동 등록 (유튜브 API 는 핀 고정 기능이 없어
           상단 고정 핀만 앱/웹에서 1클릭)
    ② 인스타 릴스 패키지 + 체크리스트
       - MP4 + 캡션 + 고정댓글 + 체크리스트가 ZIP 으로 저장됩니다.
       - 인스타는 앱에서 직접 업로드합니다(웹 자동화 차단).
    ③ 로컬 MP4 + 카피만 저장

[6] [채널 전략] 탭 → [다시 분석]
    - 채널 영상의 조회수·좋아요·댓글·길이·업로드 시간대를 분석해
      · 가장 반응 좋은 음식 카테고리
      · 가장 반응 좋은 영상 길이(초)
      · 골든타임 업로드 시각
      을 계산해 카드로 보여 줍니다.
    - [✅ 이 전략으로 바로 제작하기] 를 누르면 추천 주제·길이·시간이 그대로 세팅되어
      바로 제작이 시작됩니다.
    - [댓글 답글] 탭에서는 국내(한국어)·해외(영어) 댓글에 맞는 재치 답글 초안을
      두 가지로 보여 주고, 원클릭으로 등록합니다.


■ 수정 지시 (가장 강력한 기능)
---------------------------------------------------------
프로젝트를 연 뒤 [✏️ 수정 지시] 칸에 한 줄로 적고 [지시 반영]:
   "3컷 더 빠르게, 치즈 늘어나는 소리 크게"
   "전체 19초로 늘리고 마지막 컷 길게"
   "훅을 Can you handle Lv.999? 로 바꿔"
   "루프 끄고 플래시 켜"
· AI 키가 있으면 장면 묘사·대사까지 다시 씁니다.
· 키가 없어도 컷 길이·효과음 볼륨·훅 문구·옵션 토글은 항상 조정됩니다.
· 컷별 장면/대사/효과음은 에디터에서 직접 고치고 [저장] 하면 됩니다.


■ API 키 (선택)
---------------------------------------------------------
[설정] 탭에서 입력하면 config/settings.json 에만 저장됩니다(절대 GitHub 에 안 올라감).
· Gemini : 대본 + 이미지 생성
· OpenAI / Claude : 대본 대안
· Kling  : 이미지를 영상으로 (Access Key + Secret Key 또는 API Key)
· GitHub : 케빈에게 이미지 요청 이슈를 바로 만들 때 (선택 · Issues 쓰기 권한)
키가 없어도 0원 협업 모드로 모든 기능을 쓸 수 있습니다.


■ 유튜브 자동 업로드 준비 (처음 한 번)
---------------------------------------------------------
1) https://console.cloud.google.com → 새 프로젝트
2) [API 및 서비스] → [라이브러리] → "YouTube Data API v3" 사용 설정
3) [사용자 인증 정보] → [OAuth 클라이언트 ID] → 애플리케이션 유형: 데스크톱 앱
4) JSON 다운로드 → 파일 이름을 client_secret.json 으로 바꿔 이 폴더의 config/ 안에 저장
5) 대시보드 [유튜브 예약] 탭 → [🔑 유튜브 로그인] → 브라우저에서 채널 선택
※ 구글 앱 심사 전에는 API 업로드가 '비공개'로만 올라갈 수 있습니다.
   → 스튜디오에서 예약/공개로 한 번만 바꾸거나, 앱 인증을 받으면 완전 무인 예약이 됩니다.


■ 이미지 0원 자동 연결 (가장 빠른 길)
---------------------------------------------------------
방법 1. 구글 AI Studio 무료 키 (완전자동)
   - [설정] → Gemini API 키 칸에 무료 키 입력
     발급: https://aistudio.google.com/apikey (무료 티어)
   - [이미지 자동 생성] 을 누르면 컷별 키프레임이 자동으로 만들어집니다.
   - 무료 한도를 넘으면 다음 날 자동 복구되며, 그동안은 방법 2로 이어가면 됩니다.

방법 2. 케빈 0원 협업 (가장 확실)
   - 프로젝트 화면의 [📤 케빈에게 이미지 요청하기] 를 누릅니다.
     · 토큰이 없으면: 깃허브 이슈 작성 화면이 미리 채워진 채로 열립니다.
       → [Submit new issue] 한 번만 누르면 케빈에게 전달됩니다. (요청서는 클립보드에도 복사됩니다)
     · GitHub 토큰이 있으면: 이슈가 바로 만들어지고 그 주소가 열립니다.
   - 케빈이 저장소의 `assets_inbox/{프로젝트ID}/` 에 kf1.png ~ kf10.png 를 올립니다.
   - 맥북은 20초마다 자동으로 `git pull --ff-only` 를 해서 새 이미지를 받고,
     **곧바로 프로젝트 kf/ 로 복사**합니다. 따로 버튼을 누를 필요가 없습니다.
     · 진행은 프로젝트 화면 로그에서 “🎉 케빈이 올린 이미지 자동 수신 완료!” 로 확인
     · 전 컷이 차는 순간 **영상 조립까지 자동으로 시작**됩니다.
   - 잠시 꺼 두고 싶으면 상단 [🔄 자동 이미지 수신 ON] 을 눌러 OFF 로 바꿉니다. (기본 ON)
   - 바로 확인하고 싶으면 [프로젝트] 탭의 [🔄 지금 수신 확인] 을 누르면 됩니다.

※ 직접 넣어도 됩니다: projects/{프로젝트}/kf/ 에 kf1.png ~ kf10.png 또는 c01.png ~ c10.png
   → 대시보드가 5초마다 자동 감지해 초록불을 켜고 다음 단계로 넘어갑니다.


■ 컷별 이미지 미리보기 · 수정·영상 제작 요청 (v1.2.0)
---------------------------------------------------------
[🖼️ 이미지 자동 감지] 카드 안에 받은 이미지가 **컷별 썸네일 갤러리**로 보입니다.
   · C01 … C10 아래에 실제 kf 이미지(kf1.png / c01.png)가 9:16 썸네일로 표시됩니다.
   · 썸네일을 누르면 원본이 새 탭에서 크게 열립니다(캐시 방지: 파일이 바뀌면 바로 새 그림).
   · 이미 클립(.mp4)이 있으면 그 컷에 🎬 클립 배지가 붙고, 썸네일은 클립 첫 프레임입니다.
   · [📋 컷 검수 메모 복사] 로 컷별 유무를 텍스트로 뽑아 케빈에게 보낼 수 있습니다.

[✏️ 케빈에게 이미지 수정 요청]
   · 카드의 C번호를 누르면 아래 수정 지시 칸에 "3번 컷 " 이 자동으로 들어갑니다.
   · 예: "3번 컷 감자 표정 더 놀라게, 9번 태극기 더 크게" → [✏️ 케빈에게 이미지 수정 요청]
   · 깃허브 이슈: 제목 [이미지수정] 프로젝트ID - 주제 · 라벨 image-revision ·
     target_inbox: assets_inbox/{프로젝트ID} · 본문에 수정 지시와 지금 컷별 장면이 들어갑니다.
   · 케빈이 같은 파일명으로 다시 올리면 20초 안에 그 컷만 교체되고, 영상도 다시 조립됩니다.

[🎬 케빈에게 영상(클립) 제작 요청]
   "이미지를 다 확인하셨으면 눌러주세요! 케빈이 Kling 구독 크레딧으로 움직이는 클립(.mp4)을
    뽑아 깃허브로 보내드립니다 (5분 내 자동 감지 / 급할 땐 톡 '요청')."
   · 깃허브 이슈: 제목 [영상제작] 프로젝트ID - 주제 · 라벨 video-request ·
     target_inbox: assets_inbox/{프로젝트ID}/clips · 컷 수·길이·컷별 움직임(motion) 지시가 들어갑니다.
   · 추가 지시(선택) 칸에 "7번 컷은 더 천천히" 처럼 적을 수 있습니다.

[클립 도착 → 자동 재조립 (중요)]
   · 정지 이미지로 final.mp4 를 한 번 만든 뒤에도, 나중에 clips/ 에 .mp4 가 채워지면
     **반드시 자동으로 다시 렌더해 움직이는 클립 버전으로 final.mp4 를 덮어씁니다.**
   · 재조립이 필요한지는 미디어 지문(컷마다 파일명·크기·수정시각)으로 판단하므로,
     이미지가 교체된 경우에도 다시 조립됩니다. 로그에
     "🎬 클립/이미지 변경 감지 → 움직이는 버전으로 다시 조립 시작 (final.mp4 덮어씁니다)" 가 남습니다.
   · 렌더가 이미 돌고 있으면 다음 차례(20초 뒤)로 미뤘다가 자동으로 다시 시도합니다.


■ 케빈에게 이미지 요청 · 자동 수신 (v1.1)
---------------------------------------------------------
[📤 케빈에게 이미지 요청하기] (프로젝트 화면)
   요청 누르시면 케빈이 5분 이내에 자동 감지해서 이미지를 깃허브로 보내드립니다.
   (따로 톡 안 주셔도 됩니다!)

   · 토큰 없이도 동작합니다
     → 깃허브 이슈 작성 화면이 미리 채워져 열립니다. [Submit new issue] 한 번만 누르세요.
       (제목: [이미지요청] 프로젝트ID - 주제 · 라벨: image-request · 본문에 target_inbox 명시)
   · GitHub 토큰을 넣어 두면 [Submit] 없이 이슈가 바로 만들어집니다
     → [설정] → GitHub 토큰 칸에 토큰 입력(Issues: Read and write 권한만 있으면 됩니다)
       토큰은 config/settings.json 에만 저장되고 GitHub 에는 올라가지 않습니다.
   · 요청서는 클립보드에도 자동 복사됩니다(보조 수단 — 톡으로 붙여넣어도 됩니다).

[🔄 자동 이미지 수신] (화면 상단 · 기본 ON)
   · 20초마다 `git pull --ff-only` 로 저장소 변경을 확인합니다.
   · `assets_inbox/{프로젝트ID}/` 에 새 이미지가 있으면 자동으로 `projects/{프로젝트ID}/kf/` 로 복사합니다.
     · 폴더명은 프로젝트 ID 와 같거나 앞부분이 겹치면 되고, `Ep.8` 처럼 편 번호만 맞아도 됩니다.
     · 같은 이름이라도 내용이 바뀌었으면 그 컷만 교체합니다(수정 요청 반영).
   · 전 컷이 차면 즉시 영상 조립을 시작하고, 로그에 “🎉 케빈이 올린 이미지 자동 수신 완료!” 가 남습니다.
   · pull 이 충돌하거나 로컬에 수정한 파일이 있으면 **로그만 남기고 계속 실행**합니다(서버 안 죽음).
   · ON/OFF 는 상단 버튼 한 번. 바로 확인하려면 [프로젝트] 탭 → [🔄 지금 수신 확인].
   · 새 프로그램 코드가 함께 내려오면 로그에 “start.command 를 다시 실행하면 적용됩니다” 가 뜹니다.


■ 아이폰(폰)에서 원격 접속하기
---------------------------------------------------------
대시보드 상단 [📱 폰에서 접속하기] 를 누르면:
   · 맥북의 현재 IP 주소와 접속 URL 이 자동으로 표시됩니다
   · QR 코드를 아이폰 카메라로 찍으면 바로 열립니다
   · PIN(4~8자리) 을 정해 두면 폰에서 접속할 때 비밀번호를 물어봅니다
   · [☕ 맥북 잠자기 방지] 를 켜 두면 화면만 꺼지고 서버는 계속 살아 있습니다

[집·사무실 — 같은 Wi-Fi]
   1) 아이폰을 맥북과 같은 Wi-Fi 에 연결
   2) [📱 폰에서 접속하기] → QR 촬영(또는 http://맥북IP:8766 입력)
   3) PIN 을 설정했다면 PIN 입력 → 끝

[외출 — 무료 Tailscale]
   1) 맥북과 아이폰에 Tailscale 앱 설치 → 같은 계정으로 로그인
   2) 맥북에서 Tailscale 켜기 → 목록에 Tailscale 주소가 자동 표시
   3) 그 주소의 QR 을 찍으면 어디서든 접속 (데이터 요금만 사용, 공유기 설정 불필요)

[보안 주의]
   · 공용 Wi-Fi 에서는 반드시 PIN 을 켜 두세요.
   · PIN 은 config/settings.json 에만 저장되고 GitHub 에는 올라가지 않습니다.
   · 집 밖에 공개하려면 Tailscale 같은 사설망을 권장합니다(공유기 포트포워딩은 비추천).

■ 자주 묻는 문제
---------------------------------------------------------
Q. "start.command" 더블클릭이 안 돼요
A. 오른쪽 클릭 → [열기]. 그래도 안 되면 터미널에서:
     chmod +x start.command && ./start.command

Q. 브라우저가 안 열려요
A. 직접 http://localhost:8766 을 여세요.

Q. "포트가 이미 사용 중" 이라고 나와요
A. 이전 창이 켜져 있을 가능성이 큽니다. 그 창을 닫고 다시 실행하세요.
   (포트 변경: config/settings.json 의 "server": {"port": 8767})

Q. 영상이 너무 느리게 만들어져요
A. 컷 준비 단계가 가장 오래 걸립니다. 처음 한 번은 인코더 감지 때문에 더 걸립니다.
   훨씬 빠르게 하려면: brew install ffmpeg

Q. 유튜브 업로드가 '비공개'로만 돼요
A. 구글 앱 심사 전 상태라 그렇습니다. 스튜디오에서 예약/공개로 바꾸거나
   Google Cloud Console 에서 OAuth 앱 인증을 완료하세요.

Q. image_request 의 c01.png 는 어디에 넣나요?
A. projects/프로젝트이름/kf/ 폴더입니다. 대시보드 [📂 폴더 열기] 로 바로 열 수 있습니다.

Q. [📤 케빈에게 이미지 요청하기] 를 눌렀더니 깃허브 로그인 화면이 나와요
A. 브라우저가 깃허브에 로그인되어 있지 않으면 먼저 로그인해야 [Submit new issue] 를 누를 수 있습니다.
   로그인하면 요청 내용이 그대로 채워진 화면으로 돌아옵니다. 로그인이 번거로우면
   [설정] → GitHub 토큰을 넣어 두세요. 그러면 [Submit] 없이 버튼 한 번으로 이슈가 만들어집니다.

Q. 케빈이 이미지를 올렸는데 아직 안 보여요
A. 상단 [🔄 자동 이미지 수신] 이 ON 인지 확인하세요(20초마다 확인).
   급하면 [프로젝트] 탭 → [🔄 지금 수신 확인].
   계속 안 되면 그 프로젝트를 한 번 열어 두세요(폴더명 매칭에 쓰입니다).
   로그에 “git pull 실패” 가 보이면 로컬에 수정한 파일이 있다는 뜻입니다 —
   터미널에서 `git stash` 후 다시 시도하거나, 대시보드를 다시 실행하세요.

Q. 자동 수신이 프로그램 코드까지 바꾸나요?
A. git pull --ff-only 로 저장소 내용을 그대로 받습니다(로컬 커밋·수정은 건드리지 않음).
   코드가 바뀌었으면 로그에 안내가 뜨고, start.command 를 다시 실행하면 적용됩니다.

Q. 클립(.mp4)을 받았는데 영상이 그대로예요
A. 클립이 도착하면 자동으로 다시 조립합니다(20초 수신 확인 → 재렌더 큐입).
   로그에 “미디어 변경 감지 → 재조립 시작” 이 보이면 정상입니다. 렌더는 몇 분 걸릴 수 있습니다.
   이미 렌더 중이었으면 다음 차례(20초 뒤)로 미뤄 두고 다시 시도합니다.

Q. 미리보기 썸네일이 안 보여요
A. 그 컷의 kf 이미지를 아직 못 받은 상태입니다(카드에 “아직 없음”). 갤러리는 5초마다 새로 고칩니다.
   파일명을 kf1.png ~ kfN.png 또는 c01.png ~ cNN.png 로 맞춰 주세요.
