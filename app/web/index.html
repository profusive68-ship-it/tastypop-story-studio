      접속 방법 자세히 (집 / 외출)
      

        집·사무실(같은 Wi-Fi)

        1) 아이폰이 맥북과 같은 Wi-Fi에 연결되어 있는지 확인

        2) 위 QR 을 카메라로 찍거나 `http://맥북IP:8766` 을 사파리 주소창에 입력

        3) PIN 을 설정했다면 PIN 입력 → 끝!


        외출 시(무료 Tailscale)

        1) 맥북과 아이폰에 Tailscale 앱 설치 → 같은 계정으로 로그인

        2) 맥북에서 Tailscale 켜기 → 위 목록에 Tailscale 주소가 자동으로 나타남

        3) 그 주소의 QR 을 찍으면 어디서든 접속 (데이터 요금만 사용)


        보안 팁

        · 공용 Wi-Fi 에서는 반드시 PIN 을 켜 두세요.

        · PIN 은 이 프로젝트의 config/settings.json 에만 저장되고 GitHub 에는 올라가지 않습니다.
