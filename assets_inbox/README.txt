assets_inbox/ — 케빈이 GitHub 로 보내 주는 이미지 보관함
=========================================================

이 폴더는 GitHub 저장소에 포함됩니다(.gitignore 예외).
프로그램 코드와 별개로, 케빈이 만들어 준 키프레임 이미지를 여기에 묶음 폴더로 올려 주면
맥북이 20초마다 자동으로 내려받아 프로젝트 kf/ 에 넣습니다. (v1.1 부터)

사용 흐름
1) 대시보드 [제작]에서 프로젝트 생성
2) 프로젝트 화면의 [📤 케빈에게 이미지 요청하기] 클릭
   · 토큰이 없으면 깃허브 이슈 작성 화면이 미리 채워진 채로 열립니다 → [Submit new issue] 한 번
   · 토큰이 있으면 이슈가 바로 만들어집니다
   · 요청서는 클립보드에도 복사됩니다
3) 케빈이 이슈를 보고 `assets_inbox/{프로젝트ID}/` 에 `kf1.png ~ kf10.png` 를 올립니다
4) 맥북이 자동으로 감지(상단 [🔄 자동 이미지 수신] ON, 기본 20초)
   → projects/{프로젝트ID}/kf/ 로 자동 복사
   → 전 컷이 차면 영상 조립까지 자동 시작
   → 프로젝트 로그에 "🎉 케빈이 올린 이미지 자동 수신 완료!" 표시

폴더 규칙
- 폴더 이름은 프로젝트 ID 와 같게 (예: ep08_불닭_치즈_떡볶이_20261122_0835)
  · 앞부분만 같아도 되고(ep08_불닭…), `Ep.8` 처럼 편 번호만 맞아도 자동 매칭됩니다.
- 이미지 이름: kf1.png ~ kf10.png (또는 c01.png ~ c10.png)
- 숫자가 컷 번호와 자동 매칭됩니다. (kf3.png → 3번 컷)
- 같은 이름으로 다시 올리면 내용이 바뀐 경우에만 그 컷을 교체합니다(수정 반영).
- 형식: png / jpg / webp, 세로 9:16 권장, 글자·로고·워터마크 없이
