assets_inbox/ — 케빈이 GitHub 로 보내 주는 이미지 보관함
=========================================================

이 폴더는 GitHub 저장소에 포함됩니다(.gitignore 예외).
프로그램 코드와 별개로, 케빈이 만들어 준 키프레임 이미지를 여기에 묶음 폴더로 올려 주면
맥북 대시보드에서 [🔄 최신 버전·이미지 받아오기] 한 번으로 내려받아 바로 쓸 수 있습니다.

사용 흐름
1) 대시보드 [제작]에서 프로젝트 생성 → [📋 케빈에게 보낼 이미지 요청서 복사]
2) 케빈에게 붙여넣기 → 케빈이 `assets_inbox/Ep8_불닭떡볶이/` 처럼 폴더를 만들어
   `kf1.png ~ kf10.png` 를 올립니다.
3) 맥북에서 [🔄 최신 버전·이미지 받아오기] 클릭 → 아래에 새 묶음이 나타납니다.
4) [📥 프로젝트에 가져오기] 클릭 → 해당 프로젝트 `kf/` 로 자동 복사되고,
   모든 컷이 차면 초록불과 함께 영상 조립이 자동으로 시작됩니다.

폴더 규칙
- 폴더 이름은 자유 (예: Ep8_불닭떡볶이)
- 이미지 이름: kf1.png ~ kf10.png (또는 c01.png ~ c10.png)
- 숫자가 컷 번호와 자동 매칭됩니다. (kf3.png → 3번 컷)
- 형식: png / jpg / webp, 세로 9:16 권장, 글자·로고·워터마크 없이
